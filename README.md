# Ledgertin Website

Landing page and marketing website for [Ledgertin](https://www.ledgertin.in/).

- **Live URL**: https://abhijith1234.github.io/ledgertin_website/

## Project Structure

- `index.html` — Main website page
- `style.css`, `style.min.css` — Website stylesheets
- `app.js`, `app.min.js` — Client-side scripts
- `sitemap.xml`, `robots.txt` — SEO and crawler indexing files
- Media assets (`*.png`, `*.svg`, `*.jpg`, `*.ico`)
